## 🚀 Featured Project

### Windows Digital Forensics Investigation

Performed an end-to-end technical investigation of Windows disk images, memory data, system files and user activity in a Windows 10 virtual environment.

The project involved:

- Analysing Windows file systems, Registry data and user accounts
- Examining browser activity, installed applications and cloud-storage artefacts
- Identifying connected USB devices and system activity
- Performing memory analysis with Volatility 3
- Conducting disk-image analysis with Autopsy
- Using Registry Explorer to examine Windows artefacts
- Verifying evidence integrity using SHA-256 hashing
- Correlating information from multiple sources to construct an event timeline
- Documenting the methodology, findings, limitations and supporting evidence

**Technologies:** Windows 10, VMware Workstation, Autopsy, Volatility 3, Registry Explorer, Python, Git and SHA-256
